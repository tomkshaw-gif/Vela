# Dashboard fonts

These unmodified Latin WOFF2 files are self-hosted. The shared family names are
`Nunito Sans` (variable weights 400 through 700) and `Lato` (700). Their declarations
are loaded with `session-dashboard.css` and are available to the local dialogs too.
Other character sets use the system fallback. No remote font requests run in the app.

Downloaded on 2026-10-21 from the Google Fonts public font service:

- Nunito Sans: https://fonts.gstatic.com/s/nunitosans/v19/pe0TMImSLYBIv1o4X1M8ce2xCx3yop4tQpF_MeTm0lfGWVpNn64CL7U8upHZIbMV51Q42ptCp7t1R-s.woff2
- Lato 700: https://fonts.gstatic.com/s/lato/v25/S6u9w4BMUTPHh6UVSwiPGQ.woff2
